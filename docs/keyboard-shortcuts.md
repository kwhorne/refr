# Keyboard shortcuts

Press **⌘/** or click **?** in the title bar for a short version of this list inside Refr.

## Files and tabs

| Command | Shortcut |
|---|---|
| Open | ⌘O |
| New blank PDF | ⌘N |
| Save workspace | ⌘S |
| Save workspace as | ⌥⌘S |
| Export PDF | ⇧⌘S |
| Print | ⌘P |
| Close tab | ⌘W |
| Next tab | ⇧⌘] or ⌃Tab |
| Previous tab | ⇧⌘[ or ⌃⇧Tab |
| Show or hide Home | ⇧⌘H |
| Keyboard and pointer guide | ⌘/ |
| Quit | ⌘Q |

## Editing

| Command | Shortcut |
|---|---|
| Undo | ⌘Z |
| Redo | ⇧⌘Z or ⌃Y |
| Copy selected text, or the selected annotation's text | ⌘C |
| Find | ⌘F |
| Delete the selected annotation | Delete or Backspace |
| Move the selected annotation 1 pt | Arrow keys |
| Move the selected annotation 10 pt | ⇧ + arrow keys |
| Cancel a drag, clear the selection | Esc |

## Tools

These work when the document has focus, not while you type in a text field.

| Tool | Key |
|---|---|
| Select | V |
| Hand | H |
| Add text | T |
| Draw freehand | D |

## View and navigation

| Command | Shortcut |
|---|---|
| Fit page | ⌘0 |
| Actual size | ⌘1 |
| Fit width | ⌘2 |
| Zoom in | ⌘+ or ⌘= |
| Zoom out | ⌘− |
| Previous page, next page | Page Up, Page Down |
| First page, last page | Home, End |
| Scroll (nothing selected) | Arrow keys |

## Text fields

In the search field, dialogs, the reply field and the inline text editor:

| Command | Shortcut |
|---|---|
| Accept | Return |
| Cancel | Esc |
| Select all | ⌘A |
| Cut, copy, paste | ⌘X, ⌘C, ⌘V |
| Start or end of the text | ⌘← / ⌘→, or Home / End |
| Extend the selection | ⇧← / ⇧→ |

## Dialogs

| Command | Shortcut |
|---|---|
| Accept | Return |
| Cancel, or close About Refr | Esc |

## Pointer

| Gesture | Does |
|---|---|
| ⌘-scroll or ⌃-scroll | Zooms around the pointer |
| ⇧-scroll | Scrolls sideways |
| Middle-button drag | Pans, with any tool |
| Drag with Hand | Pans |
| Drag across text with Select | Selects text |
| Double-click text, a comment or a stamp with Select | Edits its text |
| Drag a corner handle | Resizes the selected annotation |
| Drag a page in Organize pages | Moves it to another position |
| Double-click a page in Organize pages | Opens it in the document view |
| Drop files on the window | Opens them in new tabs |
