# Refr documentation

Refr is a local-first PDF workspace for macOS. You can read, annotate, comment, sign,
organize and export PDFs without an account, and nothing leaves your Mac.

| [Reading and navigating](reading-and-navigating.md) | Page layouts, zoom, scrolling, thumbnails, bookmarks, find and copying text |
| [Annotating](annotating.md) | Text markup, drawing, shapes, text, stamps and check marks, plus selecting, editing and undo |
| [Comments and review](comments.md) | Comments, replies, resolving and the Comments panel |

| [Keyboard shortcuts](keyboard-shortcuts.md) | Every shortcut and pointer gesture |
